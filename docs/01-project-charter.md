# Project charter

## Misión

Construir una ROM DerpFest Android 17 mantenible, reproducible y verificable para Motorola Edge 30 Neo (`miami`).

## Alcance

Incluye integración AOSP/DerpFest, device/common/kernel trees, blobs documentados, SELinux/VINTF, compilación, pruebas en emulador/dispositivo y documentación operativa.

Fuera de alcance inicial: soporte para otros modelos, distribución de firmware propietario sin licencia y cambios no trazables en el árbol fuente.

## Definition of Done

- Historia/caso de uso enlazado y criterios de aceptación cumplidos.
- Código revisado en PR pequeño y reproducible.
- Build o validación focalizada registrada; bugs conocidos documentados.
- README/documentación/ADR actualizados.
- Sin secretos, blobs no autorizados ni artefactos generados en Git.
