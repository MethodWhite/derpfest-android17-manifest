# Reporte de bugs

Todo bug debe incluir modelo/codename, build fingerprint, pasos reproducibles, resultado esperado/actual, logs con `adb logcat -b all`, `dmesg` si aplica, frecuencia, regresión y workaround.

Severidad: `S0` no arranca/pérdida de datos, `S1` función crítica rota, `S2` degradación reproducible, `S3` menor. Nunca adjuntar IMEI, tokens, dumps privados ni datos personales.
