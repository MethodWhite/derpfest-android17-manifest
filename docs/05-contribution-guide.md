# Contribution guide

Antes de cambiar: leer el charter, buscar issues/ADRs relacionados y definir validación. Después: abrir PR con alcance, riesgo, pruebas, documentación actualizada y rollback. Las revisiones deben comprobar funcionalidad, seguridad, reproducibilidad y tamaño del cambio.
